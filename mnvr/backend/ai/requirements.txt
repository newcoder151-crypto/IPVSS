# ── PyTorch — CPU-only build, on purpose ─────────────────────────────────────
# A plain `pip install torch` on Linux pulls the CUDA-bundled wheel, which
# drags in a dozen separate NVIDIA library packages as transitive
# dependencies (nvidia-cublas-cu12, nvidia-cudnn-cu12, cuda_pathfinder, ...)
# — each one large, and on a slow/flaky connection that's a lot of surface
# area for a single timeout to blow up the whole install (exactly what
# "ReadTimeoutError .../cuda_pathfinder-....whl" further down in this repo's
# history was). Pinning the explicit +cpu build below skips all of that
# entirely — smaller, faster, and far less likely to fail partway through.
#
# If you have a GPU and want it used, see the override instructions in
# SMART_SEARCH_NOTES.md — do that AFTER a normal CPU install succeeds once,
# on a day your connection is behaving.
